# IELTS Boot Camp

Сайт для подготовки к IELTS Academic: 3 полных теста, уроки, практика по всем навыкам, автоматическая проверка Writing и Speaking, словарь, личный кабинет.

## Запуск
Откройте `index.html` двойным кликом. Сервер не нужен. Шрифты подгружаются из Google Fonts (без интернета сайт работает на системных).
Прогресс хранится в браузере (`localStorage`); перенос на другой компьютер — «My Locker → Экспорт / Импорт».
Для записи голоса и распознавания речи нужен Chrome/Edge и доступ к микрофону (при открытии с `file://` разрешение может запрашиваться каждый раз — удобнее запускать через любой локальный сервер).

## Что внутри
- **Practice Tests** — 3 полных теста (Test 1–3):
  - Listening: 4 части, 40 баллов; Reading: 3 текста, 40 баллов; типы заданий как на экзамене: T/F/NG, Y/N/NG, matching headings, matching information, multiple choice, **choose TWO** (2 балла, частичный зачёт), completion, matching.
  - Writing: Task 1 (график/таблица/диаграммы) + Task 2 прямо в тесте, оценка Writing = (Task 1 + 2 × Task 2) / 3.
  - Speaking: Part 1 и Part 2/3 к каждому тесту; оценка подтягивается в Overall.
  - Режимы **Timed** (Listening 30 мин, звук один раз; Reading 60 мин; Writing 60 мин) и **Untimed**. После теста — разбор, разбивка по типам заданий, Overall по правилу округления IELTS.
- **Course** — 14 уроков и практика по отдельным частям тестов (+ 8 мини-тренировок).
- **Writing** — 4 Task 1 и 6 Task 2, образцы ответов (все выше минимума по словам), редактор с таймером, анализатор, самооценка.
- **Speaking** — 10 тем Part 1, 8 карточек Part 2 + Part 3; озвучка вопросов, запись, таймеры подготовки и монолога, распознавание речи.
- **Vocabulary** — 110 слов, интервальное повторение. **Exam Guide / Band Calc** — формат, таблицы, калькулятор Overall. **My Locker** — билет, табель, значки, динамика тестов, слабые типы заданий, настройки проверки, профили.

## Автоматическая проверка (js/grade.js)
Два режима, их можно использовать вместе:
1. **Офлайн-эвристики** (без ключа и сети). По каждому из 4 критериев считаются признаки и выдаётся Band с пояснениями:
   - Writing: объём относительно минимума, overview (Task 1), покрытие данных графика, позиция/заключение/примеры/релевантность (Task 2), связки и их перегруз, абзацы, длина предложений, разнообразие и академическая лексика, повторы, орфография (список частых ошибок), ~20 грамматических паттернов (артикли, согласование, модальные, времена и т. д.), сокращения, разговорные слова.
   - Speaking: темп (слов/мин), объём ответа, слова-паразиты, связки, лексика, придаточные, ошибки; произношение — только косвенно по уверенности распознавания речи.
   - Потолок офлайн-оценки — 7.5: эвристики не отличают 8–9 от 7, не понимают смысл и аргументацию. Точность ≈ ±1 band.
2. **Claude API** (оценка «как экзаменатор»): текст/транскрипт, задание и данные графика отправляются в модель с инструкцией применять публичные дескрипторы IELTS консервативно; возвращаются Band по 4 критериям, разбор, цитаты ошибок с исправлениями, советы. Ключ вводится в My Locker → Настройки проверки, хранится только в этом браузере и **не попадает в экспорт**; запросы идут напрямую в api.anthropic.com и тарифицируются на вашем аккаунте.

## Как посчитан Band
Таблицы Academic Listening / Reading (по 40 баллов) — общеизвестные приблизительные; Overall — среднее четырёх навыков с округлением до 0.5 (.25 → .5, .75 → 1.0). Для отдельных частей (не 40 баллов) оценка условная — пересчёт на 40.

## Структура кода
- `js/core.js` — реестры, проверка ответов (включая choose TWO), таблицы Band, хранилище, статистика
- `js/grade.js` — офлайн-оценка, Claude API, распознавание речи; `js/tools.js` — озвучка, запись, SVG-графики, анализатор текста
- `js/views.js` — экраны; `js/acts.js` — действия; `js/exam.js` — пробный тест; `js/campus.js` — мотивация; `js/main.js` — роутер
- `data/test{1,2,3}-{listening,reading}.js` — полные тесты; `data/tests.js` — состав тестов; `data/writing.js`, `speaking.js`, `vocab.js`, `lessons.js`; `data/reading.js`, `listening.js` — мини-тренировки
- `tools/check.html` — проверка данных (открыть через локальный сервер; должно быть «ВСЁ ОК»): 40 баллов на навык в каждом тесте, валидность ответов, наличие ответов в тексте/скрипте, объём образцов Writing

## Как добавить задания
В массив `qs` набора (`data/test*-reading.js` / `-listening.js`):

```js
tf('Statement.', 'T', 'Объяснение'),                       // T / F / NG
yn('Statement.', 'Y', 'Объяснение'),                       // Y / N / NG
mc('Question?', ['A', 'B', 'C'], 1, 'Объяснение'),         // ответ — индекс
ms('Choose TWO.', ['A', 'B', 'C', 'D', 'E'], [0, 3], ''),  // два верных, 2 балла
gap('Complete: ___', ['word', 'alt'], 'Объяснение'),       // допустимые варианты
sel('Paragraph A', headings, 0, 'Объяснение'),             // выбор из общего списка
```
`group('Инструкция', [...])` добавляет заголовок к блоку. Новый тест регистрируется в `data/tests.js`; в каждом тесте должно быть ровно 40 баллов на Listening и на Reading.

## Оговорки
- Все материалы авторские (официальные тесты Cambridge, IDP, British Council защищены авторским правом). Данные в графиках Writing вымышленные.
- **Объём:** тексты Reading ≈ 760–820 слов (на экзамене обычно 700–900; три текста ≈ 2 400 слов), записи Listening ≈ 560–700 слов на часть (≈ 2 400–2 650 слов на тест; на экзамене запись длится около 30 минут, у нас — около 15–18 минут синтезированной речи). Формат, типы заданий, число баллов и тайминги — как на экзамене.
- **Listening** озвучивает синтезатор речи браузера: нет акцентов, фонового шума и пауз на проверку ответов; в Timed-режиме звук запускается кнопкой и играет один раз. Тренируйтесь и на настоящих записях.
- **Баллы приблизительные:** официальный пересчёт у каждого теста свой. Офлайн-оценка Writing/Speaking ограничена (см. выше); оценка Claude ближе к экзаменатору, но тоже не заменяет официальную проверку. Произношение по тексту оценить нельзя.
- Распознавание речи зависит от браузера и сервиса распознавания; если оно недоступно, вставьте или напечатайте транскрипт вручную.
- Тестов три: повторные прохождения покажут те же задания.
